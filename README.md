# 🤟 Sign Language Detection using MediaPipe & OpenCV

A real-time **Sign Language Detection System** built using **Python, OpenCV, and MediaPipe**. This project detects hand landmarks through a webcam feed and recognizes multiple static hand gestures using finger-state analysis.

---

## 🚀 Features

* 🎥 Real-time webcam-based gesture detection
* 🖐️ Hand landmark tracking using MediaPipe Hands
* ⚡ Fast and lightweight implementation
* 🤖 Detects multiple sign gestures instantly
* 📌 Finger-state based gesture recognition logic
* 🧠 Beginner-friendly computer vision project

---

## 🛠️ Tech Stack

* **Python**
* **OpenCV**
* **MediaPipe**
* **NumPy**

---

## 📂 Project Workflow

1. Capture live webcam feed using OpenCV
2. Detect hand landmarks using MediaPipe
3. Analyze finger positions and distances
4. Convert finger states into gestures
5. Display detected sign on screen in real-time

## 🧠 How It Works

The project uses **MediaPipe Hands** to detect 21 hand landmarks in real time. Finger positions are analyzed to determine whether fingers are open or closed. Based on predefined finger-state combinations, gestures are mapped to specific sign labels.
